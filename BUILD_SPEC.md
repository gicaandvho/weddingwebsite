# Gica & Vho Wedding Website --- Build Specification v2

## Design Direction Update --- August 2026

This document supersedes the earlier visual direction where the website
was primarily cream/ivory with a light RPG dashboard layout.

The new visual reference establishes a **more editorial, refined,
retro-game wedding interface**:

> **Elegant retro wedding campaign × vintage game menu × modern
> editorial layout**

The website should feel intentional, restrained, premium, and cohesive.

The uploaded visual reference is the primary inspiration for the updated
Home/Quest Hub composition.

------------------------------------------------------------------------

# 1. New Visual Direction

## Core principle

### Wedding first, retro game second --- but with a stronger visual identity.

The previous design used cream as the overall page background. The new
direction should instead use a **deep muted blue/slate background as the
primary canvas**, with warm ivory content panels and burgundy accents.

The game influence should come primarily from:

-   terminology
-   numbered cards
-   small pixel-inspired icons
-   campaign labels
-   structured menu cards
-   restrained decorative symbols

It should NOT look like a conventional gaming dashboard.

# 3. Typography

The typography should be more editorial and less obviously "pixel game."

## Display font

Use an elegant serif for major titles.

Suggested:

``` text
Cormorant Garamond
```

Use for:

-   Gica & Vho
-   page titles
-   major headings
-   romantic statements

## Utility / game font

Use a restrained pixel/monospace-style font.

Suggested:

``` text
Pixelify Sans
```

or another lightweight pixel-inspired font.

Use only for:

-   labels
-   numbers
-   small navigation text
-   campaign labels
-   buttons
-   card numbers
-   countdown labels

## Body font

Use a readable serif or refined sans-serif.

Do not use the pixel font for paragraphs.

------------------------------------------------------------------------

# 4. Global Layout Philosophy

The website should no longer use the previous RPG dashboard structure.

Do NOT use:

-   permanent left sidebar
-   permanent right quick-info rail
-   3-column dashboard
-   fixed bottom navigation
-   multiple navigation systems

Use a **centered editorial composition**.

The page should feel like a beautifully designed wedding campaign
landing page.

# 23. Performance

The new color/design direction must NOT increase image usage.

Continue the existing performance rules:

-   HTML/CSS for interface
-   SVG for icons
-   WebP for artwork
-   lazy-loaded photographs
-   no full-page background images
-   no large PNG UI
-   no video background
-   no GIF UI
-   no external animation libraries

Target:

``` text
Fast first paint
Minimal initial assets
Progressive image loading
```

------------------------------------------------------------------------

# 24. Asset Strategy

The visual reference does NOT mean the website should become
image-heavy.

Use actual artwork only where it adds value.

Priority assets:

``` text
1. Hero / couple artwork
2. Optional campaign map
3. Actual wedding/pre-wedding photos
4. Outfit reference images
5. Small decorative SVGs
```

Everything else should remain HTML/CSS.

# 26. Important Design Rule

The visual reference should be treated as a **design language
reference**, not a pixel-perfect template.

We should preserve:

-   color relationship

-   card structure
-   typography hierarchy
-   restrained game vocabulary
-   editorial spacing

But we should still make the final site uniquely Gica & Vho.

# 28. Final Design Goal

The finished website should feel like:

> **A sophisticated wedding invitation designed as a vintage co-op
> campaign.**

Not:

> a gaming website with wedding information.

The visual balance should be approximately:

``` text
40% elegant editorial wedding
30% vintage / retro visual identity
20% personal storytelling
10% game terminology
```

The website should be beautiful even if the visitor has never played a
video game.
